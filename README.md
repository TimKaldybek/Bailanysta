# Bailanysta

**Bailanysta** («байланыс» — «связь» на казахском) — это iOS приложение, которое помогает людям общаться друг с другом. Делать посты и делиться важными моментами или интересными вопросами с читателями.

## Быстрый старт

**Требования:** Xcode, симулятор iOS или устройство.

```bash
open Bailanysta.xcodeproj
```

Зависимости Swift Package Manager разрешаются автоматически при первом открытии проекта. Сборка — `Cmd+B`, запуск — `Cmd+R`.


## Что есть в приложении

**Вход**
- Вход через Google, по email/паролю или гостевой (анонимный) вход — придумайте смешной имейл и имя пользователя, если не хочется регистрироваться по-настоящему.

**Лента**
- Публикуйте посты с текстом, картинкой и категорией (Design / Tech / Updates / General).
- Лайкайте посты, открывайте комментарии тапом по посту, делитесь постом через системный шеринг.
- Лента живая — новые посты появляются сразу у всех, без обновления вручную.

**Комментарии**
- Открывайте обсуждение под любым постом и оставляйте свои комментарии.

**Профиль**
- Свой профиль с вкладками «Посты» / «Ответы» / «Лайки», просмотр чужих профилей, подписка/отписка.

**Поиск**
- Trending-темы — тап открывает ленту, отфильтрованную по теме.
- Популярные хэштеги — собираются из постов пользователей в реальном времени и тоже кликабельны.
- Поиск постов по ключевому слову или хэштегу, история последних запросов.
- Рекомендованные пользователи с быстрой подпиской.

**Уведомления**
- Лента алертов: лайки, комментарии, упоминания, ответы, приглашения.

**Настройки**
- Тема оформления (светлая / тёмная / системная), смена языка, шаринг приложения, уведомления, выход из аккаунта.

**Локализация**
- Полностью на трёх языках: русский, казахский, английский.

**Разное**
- Функции в разработке аккуратно помечены боттомшитом «Coming soon», а не молчаливо неработающей кнопкой.


## Технологический стек

| Область | Решение |
|---|---|
| Язык | Swift |
| UI | Программный UI (без Storyboard/XIB, кроме экрана запуска) |
| Архитектура | Coordinator + MVP |
| Вёрстка | SnapKit |
| Бэкенд | Firebase (Firestore) |
| Сеть | Alamofire |
| Изображения | Kingfisher |
| Аналитика / шаринг | Facebook SDK |
| Управление зависимостями | Swift Package Manager |
