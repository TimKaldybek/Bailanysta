# Bailanysta

**Bailanysta** («байланыс» — «связь» на казахском) — это iOS-игра-«ледокол» (icebreaker), которая помогает людям раскрепощённее общаться друг с другом. Игроки выбирают тему, бросают кубик, чтобы получить вопрос, и отвечают на него вместе — вопросы охватывают такие темы, как отношения, мечты, карьера, забота и другие, а режим «случайно» подбирает вопрос неожиданно.

## Возможности

- **Выбор темы** — можно выбрать одну или несколько категорий вопросов (бесплатным пользователям доступно не более 2 тем)
- **Бросок кубика** — анимированный бросок кубика (с тактильной отдачей) открывает следующий вопрос
- **Лента вопросов** — просмотр и ответы на локализованные наборы вопросов из встроенного контента
- **Профиль и поиск** — отслеживание активности и поиск контента внутри приложения
- **Подписка** — снятие ограничений на темы и вопросы через пейвол на базе RevenueCat (тарифы на месяц / 3 месяца / год)
- **Обратная связь** — отправка фидбэка команде, с ограничением не чаще одного раза в 24 часа
- **Локализация** — контент и интерфейс подстраиваются под язык устройства

## Технологический стек

| Область | Решение |
|---|---|
| Язык | Swift |
| UI | Программный UI (без Storyboard/XIB, кроме экрана запуска) |
| Архитектура | Coordinator + MVP |
| Вёрстка | SnapKit |

| Сеть | Alamofire |
| Изображения | Kingfisher |
| Аналитика / шаринг | Facebook SDK |
| Управление зависимостями | Swift Package Manager |

## Архитектура

Приложение построено по паттерну **Coordinator + MVP**:

- **Координаторы** отвечают за всю навигацию. `AppCoordinator` запускает приложение из `SceneDelegate` и делегирует управление `MainFlowCoordinator`, который переключает между флоу игры, подписки и настроек.
- **MVP** на каждом экране: `ViewController` отвечает только за UI, а `Presenter` — за логику и связь через delegate-протоколы.
- **Фабрики** (`CoordinatorFactory`, `ModuleFactory`) создают координаторы и view controller'ы, собирая всю инъекцию зависимостей в одном месте.

Вопросы упакованы в JSON-файлы с учётом локали (например, `job-en.json`, `sex-ru.json`) и загружаются в зависимости от языка устройства.

## Быстрый старт

**Требования:** Xcode, симулятор iOS или устройство.

```bash
open Bailanysta.xcodeproj
```

Зависимости Swift Package Manager разрешаются автоматически при первом открытии проекта. Сборка — `Cmd+B`, запуск — `Cmd+R`.

## Структура проекта

```
Bailanysta/
  Core/            Координаторы, фабрики, общая инфраструктура приложения
  Modules/         Фичевые модули (Feed, Settings, QuestionModule и др.), у каждого свои View/Presenter
  Resources/        App delegate, конфигурация запуска
  Core/Mock Data/   Встроенные JSON-файлы с вопросами
```
